功能参考帕秋莉手册，基于LDLib2的UI系统去实现的

编辑器目标

同时支持Markdown的编写习惯以及按钮的可视化编辑，尽可能实现无需记住编写语法也能通过可视化去编辑组件。

为了考虑丰富的功能，编辑器效果和文本的转换采用html结构，但是在玩家输入内容的时候，同时去检测玩家输入的文本结构是否符合Markdown的语法

例子

粗体文本你可以在预览模式下通过选择文本后，点击编辑器上的按钮来实现加粗；也可以选择在代码模式下通过输入指定的html结构来实现出现加粗文本

粗体 <----------> <strong>粗体</strong>

但是你可以选择在预览模式下直接输入Markdown的语法也就是 **粗体**，编辑器会在你输入文本的时候正则匹配你的结构是否符合Markdown的语法标准，比如按照上面这个案例你会在输入最后一个*的时候发现，你输入的这一段文本变成了粗体

选做方案：对于这些可以直接按一下按钮就可以改变类型的组件，可以考虑加入快捷键编辑。比如玩家选中一段文本后按下Ctrl/Cmd+B就可以实现一键切换粗体状态

组件元素

html元素仅供参考，实际可以根据AI编写的为准😀

非MC元素

粗体

效果展示：粗体

Markdown语法：**粗体**

html结构：<strong>粗体</strong>

斜体

效果展示：斜体

Markdown语法：*斜体*

html结构：<em>斜体</em>

删除线

效果展示：删除线

Markdown语法：~~删除线~~

html结构：<s>删除线</s>

超链接

效果展示：超链接

Markdown语法：[链接文字](URL地址)

html结构：<a href="URL地址">链接文字</a>

上标和下标

效果展示：22和H2O

Markdown语法：^上标^ 和 ~下标~

html结构：<sup>上标</sup> 和 <sub>下标</sub>

隐藏文本

效果展示：隐藏文本

Markdown语法：||隐藏的秘密||

html结构：<span class="spoiler">隐藏的秘密</span> （无专属标签，需自己配置样式）

左对齐

右对齐

无序列表

  • 一层列表

    • 二层列表

      • 三层列表

有序列表

  1. 有序列表

Markdown语法：1. 列表项

html结构：<ol><li>列表项</li></ol>

引用块

引用块

水平线

效果展示：

Markdown语法：---（单独成行）

代码块

效果展示：

let a = 1;

Markdown语法：

```javascript
let a = 1;
console.log(a)
```

html结构：<pre><code class="language-javascript">代码内容</code></pre>

行内代码

效果展示：行内代码

Markdown语法：`行内代码`

html结构：<code>代码</code>

任务列表

效果展示：

  • 未完成任务

  • 已完成任务

Markdown语法：- [ ] 未完成任务 / - [x] 已完成任务

html结构：<ul class="task-list"><li><input type="checkbox" disabled /> 待办事项</li></ul>

图片

效果展示：

Markdown语法：![图片描述](图片路径)

html结构：<img src="图片路径" alt="图片描述" />

特别声明：图片支持资源包图片，网络图片，base64

表格

效果展示：

1-1 1-2
2-1 2-2

| 表头1 | 表头2 |
| ----- | ----- |
| 内容1 | 内容2 |

html结构：

<table withheaderrow="false" data="1-1,1-2,2-1,2-2" data-type="custom-table"
  data-with-header-row="false">
  <tbody>
    <tr>
      <td>1-1</td>
      <td>1-2</td>
    </tr>
    <tr>
      <td>2-1</td>
      <td>2-2</td>
    </tr>
  </tbody>
</table>
